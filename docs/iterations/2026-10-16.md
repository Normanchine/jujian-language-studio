# 2026-10-16：句间精听迭代与 Windows 打包

## 最终界面与交互

- 视频居中、保持源画面比例；下方为一行一张的连续完整字幕卡片。视频下方可上下拖动，播放器底栏压缩为紧凑布局。
- 原文统一加粗。当前片段使用很浅的主题底色、左侧强调色条；最终按用户反馈，当前单词使用透明底与 1.5px 主题色边框。
- 高亮延迟提供 0/100/200/300/400/600 毫秒，默认 200 毫秒。延迟与视频高度会保存；200 毫秒是用户试听接受的校准起点，不是强制对齐精度结论。
- 手动浏览时停止自动跟随，“回到当前句”恢复。上一句、下一句、播放/暂停、循环均支持自定义快捷键。
- 修复播放结束后进度归零覆盖历史的问题，媒体自然结束保存“已听完”。
- 16px 窗口圆角与视频圆角使用抗锯齿遮罩。修复过渡被硬阈值抹掉、圆角呈斜切锯齿的问题。

## 字幕分段

早期 38 段字幕中，示例两段分别为 19.14 秒/48 词、22.14 秒/51 词。布局无法消除长段落本身的阅读负担。

处理采用“不可修改的原文词与源时间戳 + 标点/停顿/分句候选 + 本地模型建议 + 程序长度约束”。文字完整覆盖、词序与时间顺序必须通过检查。长句优先保持自然分句，最多 32 词、14 秒；自然的短完整句不强行凑长度。

第一轮让模型同时决定边界和翻译，出现了 dangling phrase 与译文错位，已弃用。改为候选切点选择与逐段翻译分开请求；模型建议不满足约束时回退到规则，不采用无效边界。不能把最终切点称为纯模型输出。

本地六片段试听覆盖 102 个源词，时长为 7.86、7.96、2.66、7.68、11.10、1.50 秒。跨原分段补全了 `quite natural` 和 `taken a different form`；试听通过后整合进程序。

正式版提供“整理英语字幕”入口：后台处理、进度提示、原字幕备份、人工修改保护和取消时保留原数据。新英语转写也会自动生成短单元，旧的英语合并规则从 35 秒/280 字符收紧至 14 秒/180 字符。日语转写流程保持现有处理方式。

机器识别错误没有在分段中被擅自改写。机器译文仍有语气或词义问题，需要校对；结构与时间验证不能替代识别和翻译准确率评估。
