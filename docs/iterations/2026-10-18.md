# 2026-10-18 写作体验与正式版

## 写作界面

- 英语作文编辑和批改正文采用 Georgia 字体，增加段落行距；日语字体保持原样。
- 英语自由写作的空题目可收起为紧凑入口；已有题目与模拟题以卷面形式展示。
- 增加尊重 Windows 动效辅助设置的窗口启动过渡，以及跟随输入位置移动的轻柔光标动画。
- 写作素材改为连续卡片列表。AI 与个人素材按来源区分，个人素材按作文隔离；跨作文复用需显式收藏。
- 卡片展开以简洁搭配和相近表达为主，减少长篇术语和不必要的例句说明。托福练习素材提示强调切题、准确、自然和易迁移，不声称官方词表、官方评分或分数提升。

## 版本与验证

- 将首个正式语义版本定为 v0.1.0，并在设置页显示版本号。正式版完成安装与启动检查，桌面快捷方式直接打开应用程序。
- 写作改动经过定向验证、源码构建与隔离预览包启动检查；演示截图使用隔离生成的虚构作文和素材，不含个人学习记录。
