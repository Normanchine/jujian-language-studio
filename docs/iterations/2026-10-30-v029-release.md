# 0.2.9

本机正式目录更新到 0.2.9，保留旧正式版和原学习数据；此次未更新安装包。源码同步至 GitHub，个人数据、模型、构建产物和本机维护脚本不进入仓库。

## 阅读题导入

从“阅读 → 材料库 → 导入阅读题”选择文件。MD/TXT 直接读取；PDF、DOCX、PPTX、EPUB 和图片调用独立安装的本地 MinerU 环境转换。设置中指定该环境的 Python。没有云端 MinerU 路线。

优先按原排版识别文章、题目、选项和答案；复杂文本可交给本地 Ollama 或已配置的云端模型整理。多篇材料分别保存并关联自己的选择题。云端模型接收提取后的文本，不接收原始文档。默认隐藏原始答案表和正确选项，交卷后查看。缺答案时可生成标注来源的 AI 参考答案，无法完整识别的题可排除。

原文已有明确答案表时优先保留。数字 PDF 的文本层可补回 MinerU 遗漏的独立答案表；纯扫描 PDF 仍依赖识别结果。OCR、模型整理与参考答案都可能出错，多选和依赖图片的题暂不保证支持。

重复导入保留历史作答；移除材料时保留历史快照。统一了主题选择框与音视频链接输入框的右键菜单。
